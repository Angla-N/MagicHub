MagicHub

一款面向个人与团队的轻量聊天软件：深黑界面、组件化架构、插件可扩展

核心功能

先做扎实的聊天体验，再逐步开放能力

即时聊天WebSocket 实时收发、广播回显、在线状态，输入框与消息气泡一应俱全。
文件传输会话内传输文件与图片（规划中），消息与文件统一走同一条消息链路。
组件化 UI全局主题 Token + 聊天组件 CSS 分离，Base / Composite / Feature 三层组件体系。
插件系统plugins/ 目录 + manifest.json 即插即用，装上就出现在导航栏，卸载即消失。
原生扩展高频与底层能力用 Rust 通过 N-API 扩展 Node.js，保持前端轻量。
桌面端Electron 打包为 exe，H5 与桌面共用同一套前端与后端协议。

技术架构

前后端同源部署，一份代码跑通浏览器与桌面

apps/webH5 前端：登录页 / 主界面 / 聊天组件（TS + React 规划中）渲染层
apps/serverNode.js 后端：静态服务 / 账号 API / WebSocket / 插件 API服务层
apps/desktopElectron 桌面壳：内置服务 + 原生窗口，打包为 exe桌面层
core /组件体系、插件宿主、通信协议等核心库（规划中）核心层
native/rust-coreRust N-API 原生扩展：加密、文件分片、性能敏感路径（规划中）原生层
plugins /插件市场：本页即第一个插件，新闻推送等后续插件同此协议扩展层

插件协议

三步接入，装上即用

plugins/<plugin-id>/manifest.json // 元信息：名称 / 版本 / 入口 plugins/<plugin-id>/index.html // 插件页面：与主界面同源加载

后端启动时扫描 plugins/ 目录自动发现；主界面左侧导航动态渲染插件入口；点击后在聊天区打开插件视图。卸载插件只需删除对应文件夹。
